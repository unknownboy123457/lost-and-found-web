# lost-and-found-web

A web-based Lost and Found information system to report, browse, and claim lost or found items.

## Features
- **Report Lost Items:** Submit details and images of lost belongings.
- **Report Found Items:** List found items with location and contact details.
- **Browse & Search:** Filter and search items by category, status, and keywords.
- **Admin Management:** Manage user submissions, categories, and item statuses.
- **Client-Side Database / Storage:** Lightweight local database handling and mock data seeds.

## Getting Started

### Prerequisites
- Node.js (v14 or higher recommended)

### Running Locally
To run the included local server:
```bash
node server.js
```
Then open your browser and navigate to `http://localhost:8080`.
